F-002   services/support_rag.py:33 in answer()
highcacheestimated

The static prompt is re-billed at full price on every call: dynamic content (e.g. retrieved documents) is placed before the static instructions, so the prompt prefix changes on every request and cannot be cached; no cache_control breakpoint is set, so the provider never caches it.

Move static instructions to the start of the prompt and put per-request content after them. Add cache_control: {"type": "ephemeral"} on the static system block.
